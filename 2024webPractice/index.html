Focus Areas 工作重点

These are the main directions that connect the projects shown on this site. 这些是串联当前网站项目内容的几个主要方向。

Experimental Assistance 实验辅助

Designing ways to make experimental operation more precise, more accessible, and easier to use. 关注如何让实验操作更精准、更易用，也更具无障碍支持能力。

Agent Tools 智能体工具

Combining model inference with practical utility such as weather lookup and geolocation. 把模型调用和天气、地理等实用能力组合成可直接使用的小型服务。

Simulation Interfaces 模拟界面

Turning complex processes and research ideas into clearer interfaces and more understandable workflows. 把复杂流程和研究问题转化为更清晰的界面与更容易理解的流程。

Project Introduction 项目简介

Only the project names and short descriptions are shown here. Full details are available on the project page. 这里仅保留项目名称和简要介绍，完整说明请进入项目界面查看。

Arduino + Michelson Interferometer

An accessibility-oriented optical experiment control project that uses Arduino, text commands, and voice interaction to assist Michelson interferometer operation. 一个面向无障碍实验辅助的光学仪器控制项目，通过 Arduino、文字指令和语音交互来辅助迈克耳孙干涉仪的操作。

agent_service

A lightweight agent service that combines model inference, weather lookup, and geolocation. 一个结合模型调用、天气查询和地理信息解析的轻量智能体服务。

polyurethane reaction frontend

A frontend platform for organizing polyurethane reaction simulation tasks, parameters, and result viewing in an industrial application context. 一个用于组织聚氨酯反应模拟任务、参数输入和结果查看的工业前端平台，服务于实际应用场景。

wolf_sheep simulation

A simulation program inspired by research on collective predation and escape behavior, exploring how group pursuit and evasion patterns can be modeled computationally. 一个受群体捕食与逃逸研究启发的狼羊群体行为仿真程序，用于从计算角度模拟群体追逐与逃逸规律。
