Arduino + Michelson Interferometer

Embodied Intelligence / Arduino-based Experimental Assistance Module 具身智能 / Arduino 实验辅助模块

This project focuses on assisted operation for a Michelson interferometer. By using Arduino to control adjustment mechanisms and execution steps, the system can respond to voice and text commands and reduce repetitive manual intervention. The goal is to improve precision, lower the barrier to operation, and enable more independent experimentation for users with physical disabilities. 这个项目围绕迈克耳孙干涉仪的实验辅助展开，重点是通过 Arduino 控制旋钮与执行动作，使设备能够响应语音和文字输入指令，从而减少人工反复调节。项目希望同时提升实验精度、降低操作门槛，并为身体残疾者提供更独立的实验完成方式。

Arduino Michelson interferometer Accessibility Embodied Intelligence

My Contribution 我做的内容

  • Translated the experimental control idea into an Arduino-assisted module.将实验控制思路转化为可执行的 Arduino 辅助模块。
  • Designed device control logic around voice and text input.围绕语音和文字输入设计设备控制逻辑。
  • Focused on accessibility and independent operation to make the experiment more stable and usable.强调可达性与独立操作，让实验更友好、更稳定。

Project Value 项目价值

  • Reduces dependence on delicate hand operation and improves accessibility in precision experiments.减少对精细手动调节的依赖，提升精密实验的可达性。
  • Improves operational stability by lowering disturbance from direct manual contact.通过减少直接手动接触对仪器造成的干扰，提高实验操作稳定性。
  • Shows how voice interaction and mechatronic control can be applied to classical optical experiments.展示了语音交互与机电控制如何应用到经典光学实验中。

System Structure系统结构

  • The system combines command parsing, motor control, mechanical actuation, and multi-axis adjustment for interferometer operation.系统将指令解析、电机控制、机械执行和多轴调节结合起来，用于干涉仪操作。
  • Its control scope covers coarse adjustment, fine adjustment, and mirror alignment across multiple channels.它的控制范围覆盖粗调、细调以及镜面多通道对准。

Purpose and Intended Use用途与目标

  • The project is designed to support more independent experiment operation for users with limited hand mobility.这个项目旨在帮助手部操作受限的使用者更独立地完成实验。
  • It also serves as a path toward more automated and teachable optical experiment workflows.同时，它也为更自动化、更适合教学推广的光学实验流程提供了方向。

agent_service

Ollama-based Agent Service for Weather and Geolocation 基于 Ollama 的天气与地理智能体服务

This project combines Ollama's Qwen3 model with weather and geolocation modules to build a lightweight agent service that supports mixed Chinese-English queries. Given a place name or a natural-language request, the system can retrieve address details, coordinates, target-time weather information, and corresponding clothing suggestions. 这个项目通过调用 Ollama 的 Qwen3 模型，并结合天气模块和地理模块，构建了一个支持中英文混合提问的轻量智能体服务。用户给出地点名称或问题后，系统可以进一步查询地址、经纬度、目标时间天气，并给出匹配的穿着建议。

Ollama Qwen3 Weather Geolocation

My Contribution我做的内容

  • Integrated model inference, weather lookup, and geolocation parsing.整合大模型调用、天气查询和地理解析逻辑。
  • Designed a lightweight interaction flow for mixed Chinese-English input.面向中英混合输入设计轻量服务交互方式。
  • Turned location and weather output into practical clothing suggestions.把地点解析结果与天气信息进一步转为穿着建议。

Project Value项目价值

  • Combines several fragmented lookups into one natural-language workflow.把多个分散查询过程整合为一个自然语言工作流。
  • Reduces the effort required to connect location, weather, and practical planning.降低了把地点、天气和日常决策联系起来所需的操作成本。
  • Demonstrates how a model-backed tool can become directly useful in everyday scenarios.展示了一个模型驱动工具如何直接服务于日常使用场景。

polyurethane reaction frontend

Frontend for a Polyurethane Reaction Simulation Platform 聚氨酯缩聚反应计算平台前端

This project is the frontend component I built for a factory-oriented backend system focused on polyurethane condensation reaction simulation. The platform supports process observation and progress monitoring, helping users follow the transition from reactants to final products and analyze how process conditions influence polymerization outcomes. 这是我为一个工厂后端系统配套完成的前端项目，目标是为聚氨酯缩聚反应计算平台提供界面支持，用于模拟反应并监控反应进程。平台需要帮助使用者观测从反应物初始状态到最终产物形成的过程，并辅助分析工艺条件对聚合反应的影响。

Frontend Industrial Simulation Polyurethane Reaction Monitoring

  • Adjusted the interface for real industrial use rather than presentation-only output.围绕工业场景调整页面组织，使其更偏向实际使用而非纯演示。

wolf_sheep simulation

Collective Predation and Escape Simulation 狼与羊群体追逐和逃逸现象仿真

Inspired by the paper "Collective Predation and Escape Strategies," this project explores how pursuit and escape outcomes change when many predators chase many prey, and what kinds of escape patterns may be more effective. I turned the research idea into a simulation program that models wolves and sheep under ordinary movement, pursuit, and escape scenarios. 这个项目受到论文《Collective Predation and Escape Strategies》启发，关注当大量捕食者追逐大量猎物时，捕食成功与逃脱成功会呈现什么规律，以及猎物怎样逃跑更有效。我把论文中的集体捕食与逃逸问题做成了仿真程序，用来模拟狼和羊在常态、被追逐等不同情境下的行为变化。

Python Simulation Collective Behavior Paper-inspired Project

My Contribution我做的内容

  • Turned a paper-inspired research question into an executable simulation.从论文问题出发，主动将理论模型转化为程序化仿真。
  • Organized the simulation logic and runtime structure for wolves and sheep behavior.组织狼与羊群体行为的模拟逻辑与运行结构。
  • Made an abstract research topic observable and testable through code.让抽象研究问题变成可观察、可调整、可运行的程序结果。

Project Value项目价值

  • Provides a computational way to explore collective pursuit and escape behavior beyond reading the paper alone.为群体追逐与逃逸问题提供了一个可计算、可观察的研究方式，而不只是停留在论文阅读层面。
  • Helps make abstract behavioral rules more visible through simulation.让抽象的行为规则通过仿真变得更直观。
  • Shows how research inspiration can be translated into a runnable computational model.展示了如何把研究启发转化为一个可运行的计算模型。

Simulation Structure仿真结构

  • The project defines behavior through explicit formulas for alignment, repulsion, chase interaction, and final velocity update.项目通过明确公式定义了取向、排斥、追逐交互以及最终速度更新。
  • It is supported by configuration files, tests, and a notebook rather than being only a visual concept.它不仅是概念展示，还配有配置文件、测试和 notebook 支撑。

Purpose and Research Motivation用途与研究动机

  • The project is motivated by a research question about what happens when many predators pursue many prey together.项目的出发点，是研究当很多捕食者一起追逐很多猎物时会出现什么规律。
  • It aims to make those collective behavior questions testable through code and simulation.它的目的，是通过代码和仿真让这些群体行为问题变得可以被测试和观察。
